# Digital-Notebook
<br>
📌 <b>Project Overview</b><br>
The Digital Notebook is a menu-driven application that simulates a notebook system where users can create, navigate, bookmark, and delete pages efficiently.
The project demonstrates practical implementation of data structures such as Doubly Linked Lists and Stacks along with dynamic memory management.
<br>
<br>
🎯 <b>Problem Statement</b><br>
Existing digital notebooks often face issues like inefficient navigation, poor bookmarking mechanisms, and memory management limitations.
This project aims to overcome these challenges by applying suitable data structures to provide smooth page navigation and fast access to important pages.
<br>
<br>
📂 <b>Data Structures Used</b>
<ol>
  <li>1. Doubly Linked List</li>
  <ul>
    <li>Each page is stored as a node</li>
    <li>Enables forward and backward navigation</li>
    <li>Efficient insertion and deletion of pages</li>
  </ul>
  <li>2. Stack (Bookmark System)</li>
  <ul>
    <li>Stores bookmarked page numbers</li>
    <li>Implements Last In, First Out (LIFO) access</li>
    <li>Allows quick navigation to the last bookmarked page</li>
  </ul>
</ol>
<br>
⚙️ <b>Features</b>
<ul>
  <li>Add new pages with page number and content</li>
  <li>Display the current page</li>
  <li>Navigate to next and previous pages</li>
  <li>Bookmark important pages</li>
  <li>Jump to the last bookmarked page</li>
  <li>Delete the current page</li>
  <li>Display all pages in the notebook</li>
  <li>Dynamic memory handling</li>
</ul>
<br>
🧠 <b>Key Concepts Demonstrated</b>
<ul>
  <li>Real-time page navigation using pointers</li>
  <li>Stack-based bookmark implementation</li>
  <li>Efficient memory usage through dynamic allocation</li>
  <li>Handling edge cases (first page, last page, empty notebook)</li>
</ul>
